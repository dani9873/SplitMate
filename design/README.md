# Diseño

Material de diseño que no forma parte de la app ni del bundle.

- `logo/comparacion.png`: comparación del logo anterior con las dos propuestas, a tamaño
  real de ícono y splash. Se eligió la Propuesta A, que vive en `assets/brand/logo.svg`.
- `logo/propuesta-b-tu-parte.svg`: propuesta descartada, una moneda con una porción aparte.
- `logo/logo-anterior.png`: logo original, con trazo fino y el nombre incluido.
- `capturas/`: capturas de la app para revisiones y PR.

Los íconos y el splash se regeneran desde el logo con `npm run icons`.
