# Dominio

Lógica pura de SplitMate: dinero, división de gastos, saldos y liquidación de deudas.

- Sin React, sin I/O y sin dependencias de la plataforma.
- Montos como enteros en unidades menores de cada moneda, nunca `float`.
- Se desarrolla con TDD y debe quedar 100 % cubierta por pruebas.

Se construye en la Fase 1.
